One pickup line, 200 characters at most, written as if a vending machine were flirting with a passing human. The program writes the line to `/output/entry.txt`. The line is spoken by the machine itself, in its own world of vending, snacks, exact change and buttons, with the punch landing on the last few words — charming, not creepy.

## Run it

```sh
node main.ts
```
